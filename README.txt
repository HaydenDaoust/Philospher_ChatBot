PORTRAIT IMAGES
===============

Place five PNG images here, one per conversational tone:

  neutral.png       — Aristotle in a calm, neutral pose
  approving.png     — Aristotle looking pleased or warm
  skeptical.png     — Aristotle looking doubtful or questioning
  disappointed.png  — Aristotle looking disheartened
  probing.png       — Aristotle looking intensely inquisitive

Recommended style: ancient Greek red-figure pottery illustration.
Recommended size: at least 400×400 px, square crop.

The frontend will gracefully fall back to a large "Α" (alpha) character
if an image file is missing or fails to load.
